# The exact package set of the running image — a lock, not a wish list.

# app/Dockerfile installs this file (`pip3 install -r requirements.txt`) on the
# Python 3.8 that ships with Ubuntu 20.04, so what is pinned here is what runs in
# production. CI installs the same file on Python 3.8 and proves the set resolves.
#
# When a pin changes, rebuild the image and run the suite inside it, and keep the
# list sorted. To compare the lock with what an image really carries:
#
#     docker run --rm --entrypoint python3 <image> -m pip freeze

# requirements are real.
