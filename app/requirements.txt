# The exact package set of the image — a lock, not a wish list.
#
# app/Dockerfile installs this file, and so does CI, on the same Python 3.14. That
# is the point of keeping one file: the combination CI proves is the one the
# container runs. Every package is pinned, the transitive ones included, so a
# rebuild next year produces the set that was tested and not whatever pip would
# resolve that day.
#
# How it was made (27/11/2026, moving from Python 3.8): the direct dependencies
# below, resolved on python:3.14 with a 30-day cooldown, then `pip freeze`:
#
#     pip install --uploaded-prior-to P30D <the direct list>
#
# The cooldown keeps a release that is days old (and the occasional hijacked
# one, which is usually caught and yanked within days) out of the lock. A fix
# for a HIGH or CRITICAL advisory jumps it: dnspython 2.9.2 and soupsieve 4.0.0
# are the first versions that fix theirs, and are younger than 30 days. Four
# pins are held on purpose, below their newest version:
#
#     bcrypt      4.3.0   5.0 raises on a password over 72 bytes instead of
#                         cutting it, and a login would answer 500
#     SQLAlchemy  1.4.54  2.x changes the session and result APIs; a migration
#                         of its own
#     ioc-finder  6.0.1   the version the IOC extraction tests were written
#                         against; moving it changes what is extracted, and is
#                         checked on its own
#     thehive4py  1.8.1   2.x speaks only to TheHive 5; the destination talks v1
#
# Direct dependencies (what the code imports): bcrypt, beautifulsoup4,
# cryptography, dnspython (for eventlet), emoji, eventlet, Flask, Flask-Limiter,
# Flask-Login, Flask-SocketIO, Flask-WTF, ioc-finder, msal, psycopg2-binary,
# PyJWT, pyotp, python-magic, qrcode, requests, SQLAlchemy, thehive4py and
# yara-python. Everything else is pulled in by them.
#
# To see what the image really carries:
#
#     docker exec bluephish python3 -m pip freeze
#
# Keep the file sorted, and keep a transitive pin when the package that needs it
# stays. Dependabot (pip, with a cooldown) proposes the bumps, and the workflow
# builds the image and runs the suite in it for each one.
